Mortal Kombat Simulator 🥋⚡

Simulador de batalhas inspirado em Mortal Kombat desenvolvido em JavaScript.

O projeto realiza lutas entre personagens clássicos utilizando atributos como força, agilidade e resistência, além de arenas aleatórias e sistema de dados.

🎮 Funcionalidades
Seleção de personagens
Sistema de atributos
Rolagem de dados aleatória
Arenas diferentes
Definição automática do vencedor
Exibição estilizada no terminal
⚔️ Personagens disponíveis
Raiden ⚡
Shao Kahn 👑
Scorpion 🔥
Sub-Zero ❄️
Liu Kang 🐉
Kitana 🪭
🕹️ Arenas
The Street 🏙️

🚀 Tecnologias utilizadas
JavaScript
Node.js
▶️ Como executar
1. Clone o repositório
git clone https://github.com/Tiagoaraujo7/mortal-kombat.git
2. Acesse a pasta
cd mortal-kombat
3. Execute o projeto
node index.js
